# Food Catalog Tool

The maintained catalog source is split by kind and stable ID under `source/`:

```text
source/records/
├── ingredients/<safe-id>.json
├── foods/<safe-id>.json
└── dishes/<safe-id>.json
```

Each source record uses the same relative `records/` path and two-space JSON
format as the generated Android catalog. `initialize` only creates missing
records and never overwrites an existing source file. Compile source records
into runtime shards with:

```text
uv run python tools/food_catalog/catalog_tool.py validate
uv run python tools/food_catalog/catalog_tool.py normalize
uv run python tools/food_catalog/catalog_tool.py initialize
uv run python tools/food_catalog/catalog_tool.py compile
uv run python tools/food_catalog/catalog_tool.py verify-roundtrip
uv run python tools/food_catalog/catalog_tool.py inspect
```

The compiler writes generated files under `app/src/main/assets/food_catalog/`.
Every record filename is generated by replacing `:` with `_`.

To build images, put developer source files under `images/source/` and add an
explicit mapping to `images/source/mapping.json`:

```json
{
  "raw_tofu.jpg": "food:taxon:glycine_max:tofu:soft"
}
```

Then run:

```text
uv run python tools/food_catalog/catalog_tool.py build-images
```

The command generates WebP `thumb` (160 px) and `detail` (640 px) variants. It
does not delete or modify source images. Install Pillow in the project `uv`
environment before using the image command.

For source images with unclear filenames, use the interactive mapper first:

```text
uv run python tools/food_catalog/image_mapper.py
```

It displays each source image, offers search and hierarchical first-level /
second-level category filtering across all ingredients, foods, and dishes, and
writes the selected mapping atomically to
`images/source/mapping.json`. Existing mappings are skipped, and the original
source images are never renamed, modified, or deleted. Install Pillow in the
project `uv` environment for previews of JPG/PNG/WEBP files.

The category filter follows dotted-tag ancestry, so selecting `food.oil` also
shows records tagged `food.oil.animal_fat`. The food list always removes every
food ID already present as a mapping value, regardless of which source image is
currently displayed. Each source image is removed from the working queue
immediately after its mapping is saved.
